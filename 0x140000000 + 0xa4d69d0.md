### **Briefing:** 
The game crashes with an "unhandled exception" referencing "MonsterHunterWilds.exe!0x140000000 + 0xa4d69d0".

### **Likely Cause:** 
Unknown.

## **General Fixes:**

### **1. Download and insert dinput8.dll into the game's directory.**
While the reason this DLL file can fix the crash remains unknown, it is a widely reported solution.

- Navigate to REFramework's [GitHub page](https://github.com/praydog/REFramework-nightly/releases).
- The latest release should be selected by default. Scroll down to the "Assets" list, and download "REFramework.zip"
- Open Steam - Library - Right click the game - Manage - Browse Local Files
- Open the REFramework folder you previously downloaded. It should contain a file named "dinput8.dll"
- Move the dinput8.dll file from the REFramework folder to the game's directory.

Afterwards, try launching the game. If it works, you can keep the file. Otherwise, you should delete it.
