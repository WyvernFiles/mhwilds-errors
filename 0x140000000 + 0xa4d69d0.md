### **Briefing:** 
The game crashes with an "unhandled exception" referencing "MonsterHunterWilds.exe!0x140000000 + 0xa4d69d0".

### **Likely Cause:** 
Unknown.

## **General Fixes:**

### **1. Download and insert dinput8.dll into the game's directory.**
While the reason this DLL file can fix the crash remains unknown, it is a widely reported solution.

- Navigate to REFramework's [GitHub page](https://github.com/praydog/REFramework-nightly/releases).
- The latest release should be selected by default. Scroll down to the "Assets" list, and download "REFramework.zip"
- Open Steam - Library - Right click the game - Manage - Browse Local Files
- Open the REFramework folder you previously downloaded. It should contain a file named "dinput8.dll"
- Move the dinput8.dll file from the REFramework folder to the game's directory.

Afterwards, try launching the game. You may see a dropdown REFramework menu, often used for modding, which you can simply close by pressing "X" or the "Insert" button. If the game no longer crashes, you can keep the file. Otherwise, and this is a low-confidence fix, you can try installing older REFramework versions, though not far from the latest. If those fail to resolve the crash as well, you should delete REFramework and its dinput8.dll file.

### **If the fixes don't work:**
The problem might be outside your control. You can try reporting the problem to [Capcom Support](https://www.monsterhunter.com/support/wilds/en/form/consent) by filling out their technical inquiry contact form. Include your platform, and the troubleshooting steps you already took.
